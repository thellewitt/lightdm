# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this project, please **do not open a public GitHub issue** with the details.

Use GitHub's **Private Vulnerability Reporting** feature to send the report privately to the maintainer.

Please include:

* A clear description of the vulnerability
* The affected version or commit
* Steps to reproduce the issue
* Any relevant logs, configuration, or proof-of-concept information
* The potential security impact

Reports will be reviewed and investigated as promptly as practical.

## Disclosure

Security issues will be handled privately while they are being investigated and, where appropriate, corrected.

Once a fix or mitigation is available, disclosure details may be published through a GitHub Security Advisory.

## Supported Versions

The current development version and actively maintained release versions are the primary focus for security fixes.

Older or unmaintained versions may not receive security updates.
